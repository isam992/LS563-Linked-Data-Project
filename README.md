# LS563-Linked-Data-Project
This is my completed Linked Data Project for LS 563!
This data set includes a list of 50 cars introduced to the industry in the 1900s. This set focuses on randomly selected cars from around the world of various classes. Each car entry focuses on the model, manufacturer, introduction year, location of assembly, class, engine capacity in liters across the various engine types that fit the model, and the transmission types. This data set utilizes RDF schema along with Wikidata and Geonames. This linked data set focuses on aspects of cars that should be externally linked to further represent and understand the model and its evolution. Things such as models, manufacturers, assembly location, class, and transmission types are linked to external sources to enable research about the various aspects of these cars and hopefully make connections to other cars. Other aspects such as introduction year and engine capacity are less important to the research surrounding car parts, so they serve as literals. Ultimately, this data set is meant to encourage research and to draw connections between other cars worldwide.


Sample Triples: 

Model -> was manufactured by -> Manufacture 

Model -> was introduced in -> Year

Example:

The Alpina B10 Bi-Turbo was manufactured by Alpina

The Dodge Omni was introduced in 1987
